# AGENTS.md — packages.mcuhome.org

Guide for AI coding agents (and new human contributors) working in this
repository.

## What this is

The **package host**: the hash-pinned packages MCUHome tools build
against, plus the tooling that publishes them and the reference verifier
that says whether a copy of a source is trustworthy. Served as
[packages.mcuhome.org](https://packages.mcuhome.org) via GitHub Pages
from the repository root.

The design is
[ADR 0025](https://github.com/mcu-home/mcuhome-workbench/blob/main/docs/adr/draft/0025-package-distribution.md)
in the flagship repository — layout, trust model, and the rule a client
follows. Read it before changing anything about a document's shape.
`README.md` is the operator's guide; this file is the map.

## Repository map

| Path | Role |
|---|---|
| `sdk/` | **published content** — one source: its keys, mirror list, index and package files |
| `anchor.json` | the root key set, published so it can be *compared* against what a tool ships. Never something a client fetches to verify with |
| `publishing.json` | operational configuration: which upstream release feeds which source. Unsigned and read by nothing outside this repository's workflows — adding a source is an entry here, not a new workflow |
| `verify.py` | the **normative** reference implementation of the client's verification rule (ADR 0025 §9). Single file, standalone by design, stdlib + `cryptography` |
| `mcuhome/packagetool/` | the publishing tooling: key material, document header and bytes, source operations, the command line over them |
| `tests/vectors/` | the committed corpus — valid and broken sources, for testing *client* implementations before they exist |
| `tests/make_vectors.py` | how the corpus is regenerated |
| `.github/workflows/` | `ci.yml`, `publish.yml` (dispatch only), `refresh.yml` (weekly) |
| `CNAME`, `.nojekyll`, `index.html` | the Pages site itself |
| `browser.html` | the inspection view — reads `sources.json` and each source's index (parts included) in the visitor's browser. **It verifies nothing and must never claim to**: a page served by this host can say nothing about this host, so a banner and a per-download dialog say so and the copy avoids anything that reads as a promise. **No external script, ever**, either. Tests enforce both |
| `sources.json` | generated by `mcuhome.packagetool catalog` from `publishing.json`; unsigned discovery for that page only, and it says so in its own note |

## Non-obvious invariants

- **`dump()` decides the bytes.** A signature covers the exact bytes of
  a document as served, so every document this repository writes goes
  through `mcuhome.packagetool.documents.dump` and nothing re-serialises a
  parsed document to compare it.
- **`verify.py` imports nothing from this repository.** That is what
  lets it be copied next to a mirrored directory and run. The small
  duplication with `mcuhome/packagetool/` is the price and is intended —
  do not "fix" it by importing.
- **Nothing published is ever replaced or removed**: not a package, not
  an index entry, not a superseded key set. The sole exception is an
  index part no head references any more, and only after 90 days.
- **Part files are immutable and named after their content.** Adding an
  entry to a part writes a *new* file and republishes the head. Never
  rewrite a part in place — the guarantee that no cache anywhere can
  serve stale bytes under a current name is this repository's to give,
  not every client's to keep.
- **CI cannot touch `keys.json`.** It is root-signed and the root keys
  are offline; `refresh` deliberately skips it, and `status` is what
  announces its yearly renewal in time.
- **A refusal in the tooling is a feature.** `add` refuses a version
  that exists, `write_keys` refuses below its own threshold, `keygen`
  refuses to overwrite, and every document must advance its `issued`.
  When a test needs a broken artefact, it is built by going around these
  guards (see `tests/make_vectors.py`), never by loosening them.

## Commands

```sh
python3 -m venv .venv && . .venv/bin/activate
pip install -e '.[dev]'

pytest                          # the verifier against the corpus, and the tooling's refusals
ruff check . && ruff format --check .
python tests/make_vectors.py    # regenerate the corpus after a format change

python verify.py sdk --anchor anchor.json
python -m mcuhome.packagetool status --source sdk
```

## Coding standards

- **Python:** ruff (lint + format), line length 100, target 3.11+ —
  settings in `pyproject.toml`.
- Everything is **Apache-2.0**; every Python file carries SPDX headers,
  and `REUSE.toml`'s fallback covers the rest.

## Commit conventions

- Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`, …).
- Every commit is DCO-signed-off: `git commit -s`.
- Default branch is `main`.
- Design decisions belong in ADR 0025 in the flagship repository, not
  in a local ADR: what this host does is a project-wide decision.
